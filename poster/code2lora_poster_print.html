🔬 Key Findings
✓ +18.1 percentage points over pretrained baseline on cross-repo evaluation
✓ Context-based methods (RAG, ICL) underperform — retrieval noise hurts assertion completion
✓ Parametric adaptation via hypernetworks outperforms input-space context injection
✓ Shared-basis (PAW) achieves comparable accuracy with 8.5× fewer parameters
💭 Key Insight

Repository knowledge should be internalized into model parameters rather than injected as context. For assertion completion, targets depend heavily on local test context — retrieved chunks consume token budget without providing direct benefit and can shift model attention away from relevant context.

Efficiency: Single forward pass generates adapters in <10ms per repository with zero inference token overhead.
